# Система планирования уборки

Консольное приложение для планирования уборки помещений.
Заказчик создаёт задачи, привязывает их к помещению и дате,
просматривает расписание.

## Возможности

- учёт помещений (добавление, поиск, проверка вместимости, сортировка);
- учёт пользователей-заказчиков;
- создание и отмена задач уборки;
- проверка доступности помещения на дату;
- формирование расписания (задача + помещение + заказчик + дата);
- фильтрация расписания по заказчику и помещению;
- хранение данных в JSON.

## Основные классы

### Room — помещение
Атрибуты: `id`, `name`, `capacity`  
Методы: `is_suitable_for()`, `validate_capacity()`, `__str__()`

### User — заказчик
Атрибуты: `id`, `name`, `email`  
Методы: `from_data()`, `__str__()`

### CleaningTask — задача уборки
Атрибуты: `id`, `room`, `task_date`, `description`, `is_cancelled`  
Методы: `cancel()`, `__str__()`

### Schedule — расписание
Атрибуты: `id`, `task`, `room`, `user`, `scheduled_date`  
Методы: `__str__()`
