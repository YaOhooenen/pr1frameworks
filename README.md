# Система планирования уборки

## Назначение
Приложение предназначено для автоматизации процессов распределения задач по уборке помещений. Оно помогает администраторам и сотрудникам клининга составлять расписание, назначать ответственных и отслеживать статус выполнения уборки.

## Целевая аудитория
* Администраторы клининговых компаний.
* Сотрудники клининга (уборщики).
* Владельцы офисных и производственных помещений.

## Предметная область
Организация и контроль клининговых услуг. Предметная область включает в себя управление помещениями, распределение человеческих ресурсов и формирование графика работ.

## Основные сущности
- Пользователь (сотрудник, администратор)
- Помещение (кабинет, зал, коридор)
- Задача (тип уборки, приоритет)
- Расписание (время, дата, периодичность)

## Основные функции
1. Проверка доступности помещения для уборки в указанное время.
2. Назначение задачи на конкретного пользователя.
3. Проверка статуса задачи (выполнена/не выполнена).
4. *Дополнительно (для развития):* Формирование отчета о выполненных задачах.

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django;
- подключение базы данных (PostgreSQL/SQLite);
- реализация пользователей и разграничение прав доступа;
- разработка REST API;
- контейнеризация приложения (Docker);
- настройка CI/CD.
